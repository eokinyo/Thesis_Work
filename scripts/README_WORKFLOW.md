# Chapter 4 Empirical Analysis Workflow

## Overview
This directory contains a two-file analysis pipeline for Chapter 4 of your thesis:

1. **R Markdown file**: IGARCH model estimation and forecasting
2. **Python Jupyter notebook**: Comprehensive empirical analysis

---

## Workflow

### Step 1: Generate IGARCH Results (R)
```bash
# Open in RStudio or run via command line:
# Rscript -e "rmarkdown::render('Chapter4_IGARCH_Models.Rmd')"

# Or in R console:
# rmarkdown::render("Chapter4_IGARCH_Models.Rmd")
```

**This generates 5 CSV files:**
- `igarch_params_from_r.csv` — IGARCH(1,1) parameter estimates
- `igarchx_params_from_r.csv` — IGARCH-X(1,1) sentiment-augmented parameters
- `igarch_oos_forecasts_from_r.csv` — Walk-forward out-of-sample variance forecasts
- `igarch_diag_from_r.csv` — Ljung-Box diagnostics for IGARCH
- `igarchx_diag_from_r.csv` — Ljung-Box diagnostics for IGARCH-X

**Estimated runtime:** 15-30 minutes (depending on rolling window size and machine)

---

### Step 2: Run Python Notebook
```bash
# Start Jupyter Lab / Notebook
jupyter lab Chapter4_Empirical_Analysis.ipynb
```

**The notebook will:**
1. Load the 5 CSV files from R automatically (cells 4.2.2 & 4.2.4)
2. Estimate Python-based GARCH and GARCH-X models
3. Estimate Random Forest models
4. Generate one-step-ahead forecasts (walk-forward)
5. Evaluate all models with QLIKE, MSE, MAE
6. Run robustness checks (SPA, MCS, alternative metrics)
7. Output LaTeX tables and figures to `./outputs/`

**Estimated runtime:** 20-40 minutes

## Troubleshooting

### R Script Issues

**"Package 'rugarch' not found"**
```r
install.packages("rugarch")
install.packages("readr")
install.packages("dplyr")
```

**"Date parsing failed: NA dates detected"**
- Check your data file's date format (code assumes `dd/mm/yyyy`)
- Modify the parsing line in the R Markdown if needed:
```r
# Current:
df$Date <- as.Date(df$Date, format = "%d/%m/%Y")

# If your dates are in ISO format:
df$Date <- as.Date(df$Date, format = "%Y-%m-%d")
```

**"Solver failed to converge"**
- Try alternative solver: change `solver = "solnp"` to `solver = "hybrid"` or `solver = "nloptr"`
- Increase iterations or relax tolerance

### Python Notebook Issues

**"FileNotFoundError: igarch_params_from_r.csv"**
- Make sure to run the R Markdown file first (generates the CSV files)
- Verify the CSV files exist in the same directory as the notebook

**"ImportError: No module named 'arch'"**
```bash
pip install arch scipy statsmodels scikit-learn
```
